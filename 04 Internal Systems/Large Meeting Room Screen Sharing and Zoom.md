# Large Meeting Room Screen Sharing and Zoom

tags: #internship #meeting-room #zoom #screen-sharing #audio

## When this applies

Use this for screen sharing and Zoom in the large meeting room / 大會議室.

## Basic setup

1. Use the mini PC as part of the meeting-room setup.
2. Set the speaker/audio output correctly so Zoom sound uses the speaker connected through the mini PC.
3. Start or join the Zoom meeting.
4. Ask Connie to accept the Zoom invitation link.
5. Confirm both screen sharing and audio work.

## Important notes

- Screen sharing working does not automatically mean the speaker/audio output is correct.
- Check Zoom's speaker setting separately.
- The exact speaker device name is not yet recorded.
- The exact reason Connie must accept the invitation is not yet confirmed; treat this as the current workplace procedure.

```text
Screen visible?

Correct speaker selected?
```
